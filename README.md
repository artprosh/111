# Relax Gas — бот + Telegram Mini App

Копия бота из [`artprosh/gas-delivery-bot`](https://github.com/artprosh/gas-delivery-bot)
(коммит `716e0ba`) плюс Telegram Mini App — тот же магазин в виде приложения внутри Telegram.
Бот и приложение работают в **одном процессе** и с **одной базой SQLite**: заказ из приложения
уходит админу и курьерам теми же функциями, что и заказ из чата, и наоборот.

## Что умеет приложение

| Роль | Экраны |
|---|---|
| Покупатель | каталог (варианты «Новый»/«Замена», бонусы), корзина, оформление (адрес или геопозиция), услуга «Подъём на этаж»: «Нужен» / «Заберу сам» (фиксированная цена, входит в сумму заказа), оплата наличными / СБП / USDT по QR со скриншотом, активные заказы с картой курьера, история с оценкой курьера (перед «Получил заказ» оценка обязательна; если заказ закрыл курьер — приложение напомнит оценить), «Позвать администратора» |
| Курьер | свободные заказы → «Взять заказ», заказы в работе: «🚪 Я на месте» (покупателю приходит уведомление, повтор — не чаще раза в минуту), «📝 Комментарий о покупателе» и оценка покупателя — обязательна перед «Доставлен» (видят только админ и курьеры), «Доставлен» / «Не доставлен» (с причиной), передача геопозиции покупателю, ссылка на Яндекс.Карты, звонок клиенту |
| Админ | активные заказы и история: статусы, назначение курьера, повторная рассылка; цена услуги «Подъём на этаж» (вкладка «Товары», 0 — выключена); товары: добавить / изменить / скрыть / вернуть, фото для приложения; курьеры: добавить / включить / отключить |
| Админ → «Разработчик» | цвета фона и акцента, форма/заливка/анимация кнопок, порядок пунктов меню, фоновая картинка с позиционированием — сохраняется в таблицу `app_theme` для всех |

Все функции классической админки бота есть и в приложении: «👥 Клиенты» (оценка и заметка
админа, отзывы курьеров), «⚙️ Ещё» — фото шапки каталога, QR оплаты СБП/USDT, тест связи с
каналом, освободить корзины, удалить все товары и очистить историю заказов (с тем же паролем,
что в боте), а также удаление курьера и товара из архива навсегда.

## Выгрузка продаж в Excel

Админка → «⚙️ Ещё» → «📊 Выгрузка в Excel» (пароль `AdminGas`, проверяется сервером; тот же пароль — у удаления всех товаров и сброса истории заказов, в приложении и в боте).
Строка = товар или услуга («Подъём на этаж») из **доставленного** заказа, по времени
размещения: «Дата, Время, Товар / услуга, Количество, Сумма, Примечание»; внизу «ИТОГО» —
формулы `SUM`. **Суточная** — с 12:00 до 12:00 по Москве (по умолчанию последние завершённые
сутки); **общая** — с первого заказа. Файл скачивается через `Telegram.WebApp.downloadFile`
(Bot API 8.0+) или присылается ботом в чат. Перед «Очистить всю историю заказов» строки заказов
копируются в `sales_archive`, сброс пишется в `history_wipes` — в выгрузке такие строки
помечены «Товар был сброшен из истории заказов …». Сбросы, сделанные до появления архива,
восстановить нельзя. Код: `webapp/export.py` (openpyxl).

## Бот — только вход в приложение и уведомления (с 28.10.2026)

Решение владельца: работаем только в приложении, правки в бот больше не вносятся. В `main.py` остались:
- `/start` — кнопка «🛒 Магазин» (Mini App) и привязка по партнёрской ссылке `?start=p_…`;
- `/id`, `/chatid` (для подключения канала-журнала);
- приём трансляции геопозиции курьера (карта в приложении, когда оно свёрнуто);
- «🚫 Отозвать этот вход» в уведомлении о входе в карту для ПК;
- на всё остальное — «📱 Всё делается в приложении», старые кнопки отвечают «Теперь всё — в приложении».

Уведомления (`webapp/bridge.py` → функции `main.py`): курьерам — назначенные / снятые заказы, сообщения
покупателя в чате; админам — заказы, курьеры и смены, чаты и заявки; канал-журнал — как раньше.
Покупателю — только «🚪 Курьер у двери» и сообщения в чатах (от курьера и от RelaxGas).
В каждом сообщении бота одна кнопка «📱 Открыть приложение» (`NotificationsOnlyMiddleware`).
Прежнее меню бота удалено, переменная `WEBAPP_ONLY` не используется.

## Геопозиция курьера — важное ограничение

Mini App — это веб-страница. Пока она открыта на экране, геопозиция курьера передаётся
автоматически сразу после «Взять заказ» (`navigator.geolocation.watchPosition`). Когда курьер
сворачивает приложение (например, открывает навигатор), телефон останавливает JavaScript
страницы — это ограничение платформы, а не кода. Для поездки курьер включает в чате с ботом
📎 → «Геопозиция» → «Транслировать геопозицию»: это работает в фоне и пишет в ту же колонку
`orders.courier_last_lat/lon`, которую читает карта покупателя. Экран курьера прямо об этом
сообщает.

## Структура

```
main.py, db.py, config.py   бот (из gas-delivery-bot) + запуск Mini App в main()
webapp/auth.py              проверка Telegram initData (HMAC-SHA256, документация Telegram)
webapp/core.py              вся логика API поверх db.py — без aiogram/aiohttp
webapp/bridge.py            уведомления в Telegram через функции main.py (рабочий режим)
webapp/server.py            aiohttp-сервер: /, /static, /api, /api/media, /healthz
webapp/static/              index.html, app.js, style.css — без сборки
dev_server.py               локальный сервер только на стандартной библиотеке (без Telegram)
tests/test_webapp.py        тесты: initData и сценарии API на настоящей SQLite
```

Изменения в файлах бота минимальные: `config.py` (переменные `WEBAPP_*`), `main.py`
(кнопка «🖥 Открыть приложение» в меню, кнопка меню чата, запуск веб-сервера в `main()`),
`amvera.yaml` (`containerPort: 80`).

## Локальная проверка (без Telegram и без токена)

```bash
python dev_server.py --reset        # http://127.0.0.1:8090/
python -m unittest discover -s tests -v
```

Вверху страницы — полоса **DEV**: вход как покупатель, курьер или админ. Демо-база
`data/dev.sqlite3`, демо-товары и QR-заглушки создаются автоматически. Всё, что бот отправил
бы в Telegram, пишется в лог и доступно на `/api/dev/events`. Курс USDT в dev-режиме —
фиксированный **демо-курс 95 ₽** (в рабочем режиме — CoinGecko, как в боте).

## Запуск на Amvera

1. Задеплоить этот репозиторий (сборка по `amvera.yaml`, зависимости — `requirements.txt`).
2. Во вкладке проекта **«Домены»** добавить бесплатный домен Amvera с типом HTTPS
   ([документация](https://docs.amvera.ru/applications/configuration/network.html)).
3. В переменных окружения добавить `WEBAPP_URL=https://<ваш-домен>/` и перезапустить.
   Без `WEBAPP_URL` веб-сервер работает, но бот не показывает кнопку приложения.
4. Открыть бота → `/start` → «🖥 Открыть приложение» (или кнопка «Магазин» слева от поля ввода).

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `WEBAPP_URL` | — | публичный https-адрес приложения |
| `WEBAPP_PORT` | `80` | порт веб-сервера; должен совпадать с `run.containerPort` |
| `WEBAPP_HOST` | `0.0.0.0` | Amvera требует слушать все интерфейсы ([FAQ 502/503](https://docs.amvera.ru/general/FAQ/502-503-error.html)) |
| `WEBAPP_ENABLED` | `1` | `0` — выключить веб-сервер, бот работает как раньше |

> ⚠️ Один токен бота нельзя одновременно опрашивать из двух мест: если параллельно запущен
> старый `gas-delivery-bot` с тем же `TELEGRAM_BOT_TOKEN`, Telegram вернёт ошибку конфликта
> `getUpdates`. Для обкатки — отдельный тестовый бот (свой токен) или остановить старый деплой.

## Что проверено и что нет

Проверено в песочнице: 19 тестов (`initData`: валидная / подделанная / чужой токен /
устаревшая; сценарии API на SQLite: корзина, заказ наличными и по геопозиции, оплата USDT со
скриншотом, взятие заказа курьером, геопозиция, доставка, оценка, «не доставлен», действия
админа, права доступа, тема); сквозной прогон всех экранов в headless Chromium (390×844) без
ошибок JS; статическая сверка всех вызовов `webapp/bridge.py` с сигнатурами функций `main.py`.

**Не проверено** (в песочнице нет доступа к PyPI и Telegram): запуск с настоящими `aiogram` и
`aiohttp`, реальный Telegram-клиент (initData, кнопки, геолокация в WebView), загрузка карты
OpenLayers/OpenStreetMap и SDK `telegram-web-app.js` с внешних CDN, публикация порта на Amvera.
Бесплатные тайлы OpenStreetMap не предназначены для больших нагрузок
([политика](https://operations.osmfoundation.org/policies/tiles/)).
